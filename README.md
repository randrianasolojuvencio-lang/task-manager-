# Task manager (Gestionnaire de taches)
Apk web de gestion de tache permettant de planifier, filtrer par priorite et suivre l'avancement d'un projet grace a une barre de progression visuel
## Fonctionnalités
* **Gestion des tâches** : Ajout, Modification, et Suppression de tâches
* **Filtres par priorité** : Tri  rapide des tâches.
* **Suivi visuel** : Barre de progression calculant en temps réel l'avancement du projets.
## Technologies
* **HTML5/CSS3**
* **JavaScript**
